# BLine

### Factory Operations & Management System

BLine is a centralized factory management platform designed to streamline manufacturing operations, inventory tracking, sales, GST billing, dispatch, and financial management through role-based portals.

## 🚀 Key Features

- Role-Based Authentication and Access Control
- Employee Account Creation
- Customer and Supplier Management
- Product and Raw Material Management
- GST Billing and Invoice Generation
- Bill of Materials (BOM)
- Production and Inventory Management
- Order Management
- Dispatch Management
- Financial Management
- Dashboard and Business Analytics
- Email-Based Password Recovery
- PDF Generation and Reports

## 👥 User Portals

| Portal | Access |
|---|---|
| Owner | Overall factory administration |
| Admin | Administrative operations |
| Sales | Sales and order-related operations |
| Supervisor | Production and inventory operations |
| Auditor | GST billing and financial verification |

## 🛠️ Technologies Used

- Frontend: Existing project frontend framework

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

### 2. Navigate to the Project

```bash
cd BLine
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Firebase

- Create or select a Firebase project.
- Configure Firebase Authentication.
- Set up Cloud Firestore.
- Add the required Firebase configuration to the project environment.

### 5. Start the Application

```bash
npm run dev
```

Use the local URL displayed in the terminal to access BLine.
